# ENCOUNTER — Console MJ D&D 5e V4.1

Cette version conserve intégralement ENCOUNTER V4 et ajoute les profils de campagne demandés.

## Nouveaux PJ
- Nans Pointud
- Brack Mard
- Samoth Drakhys
- Rufus « Le Renard » / Ruvius D. Medani
- Kentaro Amane
- Zéphyr

Les valeurs finales, sauvegardes, 18 compétences, attaques, ressources et réserves/caveats documentés sont transcrits depuis les dossiers niveau 10 fournis. Les éléments explicitement non documentés restent marqués comme tels.

## PNJ et compagnons
- Felipe Dofil
- Golem-Bonbon
- Golem-Bonbon supérieur

Lorsque Felipe est ajouté depuis la bibliothèque, ENCOUNTER propose d’ajouter automatiquement **4 Golems-Bonbons** à la même initiative, juste après lui.

## Maharles
Les profils du PDF Maharles sont intégrés à la bibliothèque : Mâchoire de la Harde, Brise-Corne, Crieur d’Orage, Porte-Nuit, Dresseur de chaînes, Svara, Torgar, Nezhar, Crevard, Crevard supérieur, Moissonneur, Sœur Vellane, Roland, trois Zomik, Geôlier impérial, Soldat de la Brigade des Glaces et Vaylen Drakhys.

### Zanror
La version FP 10 du PDF **n’est pas intégrée**. Elle est remplacée par la version fournie directement par le MJ : **FP 22, CA 20, 405 PV, 3 actions légendaires (4 en phase 3), actions de repaire et trois phases de combat**.

## Installation GitHub Pages
Remplace tout le contenu de la V4 par les fichiers de ce dossier à la racine du dépôt. Le nouveau fichier `campaign-maharles.js` est indispensable. `service-worker.js` utilise un nouveau cache V4.1 afin de forcer la mise à jour de la PWA.

Les sauvegardes des versions précédentes restent compatibles : les nouveaux profils sont ajoutés par ID sans remettre la bibliothèque à zéro.
